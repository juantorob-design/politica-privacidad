Condiciones del servicio

El Sistema de Desvinculaciones es una herramienta de uso institucional para usuarios autorizados.

El acceso requiere autenticación y aprobación previa. Cada usuario debe proteger sus credenciales y utilizar únicamente las funciones correspondientes a su rol.

El contenido, los expedientes y los documentos consultados mediante la aplicación son de uso restringido. Está prohibido copiar, divulgar o utilizar la información para fines no autorizados.

El administrador puede suspender cuentas que incumplan estas condiciones o las políticas institucionales.

Contacto: notificaciones.trans@cali.gov.co
