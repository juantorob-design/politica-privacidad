Política de privacidad

El Sistema de Desvinculaciones utiliza Google OAuth para identificar a los usuarios y Supabase Auth para gestionar cuentas, estados y roles de acceso.

La aplicación usa los datos de perfil y correo únicamente para autenticación, control de acceso y auditoría operativa. Los expedientes y documentos se consultan solo según el rol aprobado por el Super Administrador.

No vendemos datos personales ni los utilizamos para publicidad. Los datos se almacenan en servicios institucionales autorizados y se protegen mediante controles de acceso.

Los usuarios pueden solicitar información sobre su cuenta escribiendo a notificaciones.trans@cali.gov.co.
