Política de privacidad

Última actualización: 10 de septiembre de 2026.

1. Responsable y contacto

El Sistema de Desvinculaciones es una herramienta institucional administrada por el equipo responsable del proyecto. Para preguntas, solicitudes o reclamos relacionados con privacidad, escribe a notificaciones.trans@cali.gov.co.

2. Datos que recopilamos

Al iniciar sesión podemos recibir tu nombre, dirección de correo electrónico, identificador de cuenta y foto de perfil, según los datos que proporcione el proveedor de autenticación. También registramos el estado de la cuenta, el rol asignado y los eventos necesarios para controlar el acceso.

3. Cómo usamos los datos

Usamos estos datos exclusivamente para autenticar usuarios, crear y administrar perfiles, aprobar o bloquear accesos, aplicar permisos por rol, mantener la seguridad y realizar auditorías operativas. No usamos la información para publicidad ni para vender datos personales.

4. Google, Supabase y documentos institucionales

Google OAuth se utiliza para validar la identidad. Supabase Auth y su base de datos gestionan la sesión, el perfil, el estado y el rol. Los permisos de Google Drive y Google Sheets solo se solicitan cuando son necesarios para una función autorizada y conforme al rol aprobado. Los documentos y expedientes son de acceso restringido.

5. Compartición y conservación

No compartimos datos con terceros para fines comerciales. La información se conserva mientras sea necesaria para la operación institucional, la seguridad y las obligaciones aplicables, y se elimina o anonimiza cuando ya no sea necesaria.

6. Seguridad y derechos

Aplicamos autenticación, control de acceso por roles y políticas de seguridad para proteger la información. Puedes solicitar acceso, corrección o eliminación de los datos de tu cuenta escribiendo al correo de contacto. También puedes retirar los permisos concedidos a Google desde la configuración de tu cuenta.
